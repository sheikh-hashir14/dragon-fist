# Dragon Fist: Rise of Warriors

A 2D arcade-style fighting game built in **C** using the **Raylib** graphics library. Inspired by classic fighters like *Street Fighter*, this project brings fast-paced combat, unique character abilities, and local multiplayer action to the desktop.

---

## Motivation

Our goal with **Dragon Fist: Rise of Warriors** is to turn our nostalgia for classic arcade fighting games into hands-on software development experience. Through this project, we aim to:
* Apply core C programming concepts including `structs`, `enums`, functions, state machines, and game loops.
* Explore 2D graphics rendering, sprite animations, collision detection, and keyboard input handling using **Raylib**.
* Strengthen our problem-solving, debugging, and collaborative development skills.

---

## Core Features

* **Interactive Main Menu:** Navigate between game modes, view controls, and start matches seamlessly.
* **Playable Roster:** Choose from three distinct fighters.
* **Responsive Movement:** Full support for walking, jumping, blocking, and automatic opponent facing.
* **Combat Mechanics:** Fluid punches and kicks featuring attack timing, damage calculation, knockback physics, and hitbox collision detection.
* **Multiple Game Modes:**
  * **Player vs. CPU:** Test your skills against an AI-controlled opponent.
  * **Local 2-Player:** Compete head-to-head with a friend on the same keyboard.
* **Match & Round System:** Real-time health bars, round countdown timers, and multi-round victory tracking.
* **2D Sprites & Animations:** Custom character animations and dynamic stage backgrounds.
